# 📝 My Tasks – Flutter To-Do App

A clean, minimal, and user-friendly **To-Do application built with Flutter**. This app allows users to create, search for, complete, and delete tasks, with **local persistence using SharedPreferences**.

---

## 🚀 Features

- ✅ Add new tasks
- 🔍 Search tasks in real time
- ✔️ Mark tasks as completed
- 🗑️ Delete tasks
- 💾 Persistent local storage using SharedPreferences
- 🎨 Modern UI with Material Design
- 📱 Responsive and smooth user experience

## 🎯 Usage

### Adding a Task
1. Tap the **floating action button** (+) at the bottom right.
2. Enter your task in the text field.
3. Press **Add** to save the task.

### Completing a Task
- Tap the **checkbox** next to a task to mark it as complete.
- The task text will be crossed out.

### Searching for Tasks
- Type in the **search bar** at the top to filter tasks in real time.

### Deleting a Task
- Tap the **delete icon** on any task to remove it.
